# Planilha — Cenários de teste

## Artigos da planilha

### 01 - Adicionar artigo incluído na planilha

= Artigo incluído e vinculado à revisão.

-> O artigo é adicionado à planilha com sucesso.
-> A API retorna uma resposta de sucesso.

### 02 - Visualizar artigos da planilha

= Revisão com artigos adicionados na planilha.

-> A API retorna os artigos adicionados à planilha da revisão.
-> Os artigos retornados pertencem à revisão solicitada.

## Conteúdo e linhas da planilha

### 01 - Adicionar linha

= Dados válidos para criação de uma nova linha.

-> A nova linha é adicionada à planilha com sucesso.
-> A API retorna uma resposta de sucesso.

### 02 - Atualizar célula

= Célula existente e novo conteúdo válido.

-> O conteúdo da célula é atualizado com sucesso.
-> A API retorna uma resposta de sucesso.

### 03 - Excluir linha

= Linha existente na planilha.

-> A linha é excluída com sucesso.
-> A API retorna uma resposta de sucesso.
