# Planilha — Requisitos

## Objetivo

A API deve permitir o gerenciamento de artigos, conteúdo e linhas da planilha de uma revisão.

## Requisitos Funcionais

### 01 - Adicionar artigos na planilha

= O sistema deve permitir que artigos incluídos na revisão sejam adicionados à planilha.

### 02 - Visualizar artigos da planilha

= O sistema deve permitir a visualização dos artigos adicionados à planilha da revisão.

### 03 - Adicionar linha

= O sistema deve permitir a adição de novas linhas na planilha.

### 04 - Atualizar célula

= O sistema deve permitir a atualização do conteúdo de uma célula da planilha.

### 05 - Excluir linha

= O sistema deve permitir a exclusão de linhas da planilha.
